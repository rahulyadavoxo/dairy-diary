🥛 डेयरी डायरी डाउनलोड करें

दूध का रोज़ का रजिस्टर, महीने का हिसाब और WhatsApp पर बिल — एक ऐप में। मुफ़्त।

⬇️ ऐप डाउनलोड करें (Android)

बटन दबाते ही नया ऐप सीधे डाउनलोड होगा।

कैसे इंस्टॉल करें

  1. ऊपर का बटन दबाएं, .apk फ़ाइल सीधे डाउनलोड होगी।
  2. डाउनलोड पूरा होने पर फ़ाइल खोलें।
  3. फ़ोन पूछे "Install unknown apps" — Allow / अनुमति दें चालू करें, फिर Install दबाएं।
  4. Play Protect की चेतावनी आए तो "Install anyway" दबाएं।
  5. ऐप खोलें → डेयरी मालिक — लॉग इन / नया अकाउंट → 🆕 नई डेयरी? अकाउंट बनाएं।

नए अपडेट ऐप खुद डाउनलोड करके इंस्टॉल करता है।

English

Tap the button and the latest .apk downloads directly. Open it, allow "Install unknown apps", and install. Then open the app → Dairy owner → New dairy? Create account. Updates install from inside the app.
